# Project Zero Evaluation

The benchmark is deliberately small and auditable for the hackathon prototype.

## Required comparison

1. Baseline: an LLM receives only the current incident.
2. Project Zero: the system receives the same incident and can use Hindsight memory.

Record, for each case:

- relevant historical case retrieved
- contradictory case detected
- evidence cited
- recommended next action
- human evaluator judgement

Do not fabricate accuracy. Publish the observed counts and the exact test cases.
